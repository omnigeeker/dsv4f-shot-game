# dsv4f-shot-game

CS 风格的单人第一人称射击网页游戏 —— **双模式**：10 关单线**剧情模式**（含载具战、拯救人质、checkpoint、难度选择、过场简报）+ 3 张地图自由**场景模式**。

基于 **Three.js r160（ES Module）**，含后期处理、CC0 PBR 材质与实时近似光追。

## 运行方式

> 采用 ES Module，**需要本地服务器**；线上 **Vercel 部署不受影响**。

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

线上版本：**https://dsv4f-shot-game.vercel.app**

## 模式

- **剧情模式**：10 个**单线关卡**——一条通道从出生点通到终点信标，沿途战斗推进。目标多样：抵达终点 / 拯救人质 / 清剿 / 守波 / **开坦克 / 乘机枪快艇** / 击败首领。难度可选手普通/困难。沿路设置 **checkpoint**，阵亡后从检查点满血重生并保留进度；每关开始有**任务简报过场**。通关解锁下一关（localStorage 存档）。
- **场景模式**：3 张地图（废弃军事基地·夜晚 / 沙漠小镇·白昼 / 霓虹实验室·赛博），无限波次生存。

## 画面技术

- **实时近似光追**：4096 高精度软阴影、投影探照灯、GTAO 环境光遮蔽、UnrealBloom 辉光、按地图曝光调校、IBL 环境反射、ACES 色调映射
- **CC0 PBR 材质**：ambientCG（混凝土/泥土/沙地/锈金属/木箱）
- **精细化角色**：胶囊体士兵（头盔+发光面罩、防弹背心）；Boss 红色巨体
- **载具**：坦克（驾驶+炮塔+炮弹爆炸）、机枪快艇
- 五把武器、完整 HUD（任务目标/血甲/弹药/武器槽位/小地图）、加血包、护盾

## 技术栈

- Three.js r160（ES Module，CDN）+ 后期处理（EffectComposer/GTAO/Bloom/Output）
- 程序化单线地图生成器、载具系统、GLTFLoader 管线就绪
- localStorage 剧情存档（解锁/checkpoint 续玩）
