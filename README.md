# dsv4f-shot-game

CS 风格的单人第一人称射击网页游戏 —— 废弃军事基地（夜晚）。

基于 **Three.js**，纯原生 HTML/CSS/JS，无构建步骤，本地双击 `index.html` 即可运行。

## 运行方式

```bash
# 方式一：直接双击 index.html 打开
# 方式二：本地起一个静态服务器
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

## 操作

| 按键 | 功能 |
|------|------|
| 鼠标 | 瞄准 / 开火 |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 疾跑 |
| `Space` | 跳跃 |
| `C` | 下蹲 |
| `R` | 换弹 |
| `1` / `2` | 切手枪 / 步枪 |
| `Esc` | 暂停 |

## 玩法

- 单人作战，对抗一波波刷新的恐怖分子机器人。
- 存活击杀尽可能多的敌人，每波敌人更强、更多。
- 血量耗尽即死亡，可重新开始。

## 功能特性

- 废弃军事基地：混凝土墙、锈蚀集装箱、油桶、沙袋、岗亭、泛光灯、夜雾
- 手枪 + 步枪：后坐力、动态散布、曳光弹道、命中特效、换弹、切枪
- 机器人 AI：追击避障、视线开火、受击反馈、死亡动画、波次递增
- 完整 HUD：血量/护甲/弹药/动态准星/击杀/波次/命中标记/击杀播报/受伤方向/小地图
- WebAudio 程序合成音效，零外部资源

## 技术

- Three.js r159（本地化 `vendor/three.min.js`，离线可用）
- 程序化 Canvas 贴图、ACES 电影级色调映射、实时阴影、粒子特效
