# dsv4f-shot-game

CS 风格的单人第一人称射击网页游戏 —— **双模式**：10 关线性**剧情模式**（带 checkpoints 与难度选择）+ 3 张地图自由**场景模式**。

基于 **Three.js r160（ES Module）**，含后期处理与 CC0 PBR 高清材质。

## 运行方式

> 本项目采用 ES Module，**需要本地服务器**（不再支持双击 index.html），线上 **Vercel 部署不受影响**。

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

线上版本：**https://dsv4f-shot-game.vercel.app**

## 模式

- **剧情模式**：10 个线性关卡，各有目标与场景；可选手普通/困难难度；关键节点 **checkpoint**——阵亡后从检查点满血重生、保留击杀进度；通关解锁下一关（localStorage 存档）。
- **场景模式**：3 张地图（废弃军事基地·夜晚 / 沙漠小镇·白昼 / 霓虹实验室·赛博），无限波次生存。

## 画面技术

- **实时近似光追**：4096 高精度软阴影、投影探照灯、GTAO 环境光遮蔽、UnrealBloom 辉光、按地图曝光/辉光调校、IBL 环境反射、ACES 电影级色调映射
- **CC0 PBR 材质**：ambientCG（混凝土/泥土/沙地/锈金属/木箱）含法线+粗糙度
- **精细化角色**：胶囊体士兵（头盔+发光面罩、防弹背心、背包、细节武器）；Boss 红色巨体
- 五把武器、完整 HUD（任务目标/血甲/弹药/武器槽位/小地图）、加血包、出生/波次护盾

## 技术栈

- Three.js r160（ES Module，CDN）+ 后期处理（EffectComposer/GTAO/Bloom/Output）
- GLTFLoader 管线就绪（可接外部 3D 模型）
- localStorage 剧情存档
- 贴图加载失败自动回退程序化贴图
