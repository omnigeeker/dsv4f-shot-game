# dsv4f-shot-game

CS 风格的单人第一人称射击网页游戏 —— **三张地图**可选（废弃军事基地·夜晚 / 沙漠小镇·白昼 / 霓虹实验室·赛博），支持后期处理与 PBR 高清材质。

基于 **Three.js r160（ES Module）**，无构建步骤。

## 运行方式

> 本项目采用 ES Module，**需要本地服务器**（不再支持双击 index.html），线上 **Vercel 部署不受影响**。

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

线上版本：**https://dsv4f-shot-game.vercel.app**

## 操作

| 按键 | 功能 |
|------|------|
| 鼠标 | 瞄准 / 开火 |
| 按住右键拖动 | 转视角（指针锁定未生效时兜底） |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 疾跑 |
| `Space` | 跳跃 |
| `C` | 下蹲（枪更稳 · 目标更小 · 受伤更少） |
| `1` `2` `3` `4` `5` | 切 步枪 / SMG / 霰弹枪 / **狙击枪** / 手枪 |
| 鼠标滚轮 | 循环切枪 |
| 右键（锁定鼠标时） | 狙击枪开镜/关镜 |
| `R` | 换弹（带下探-回升动作） |
| `Esc` | 暂停 |

## 玩法

- 选择作战场景，对抗一波波恐怖分子机器人；开局 **5 秒护盾**，**每波再给 3 秒**。
- **狙击枪**一枪毙命、右键开镜；蹲下更稳更抗揍；地图上有**加血包**（+30）。
- 存活击杀尽可能多的敌人，每波更强；血量耗尽即阵亡，可重新出击。

## 功能特性

- **三张地图**：废弃军事基地（夜雾+探照灯+体积光）/ 沙漠小镇（阳光+云朵+棕榈）/ 霓虹实验室（冷色霓虹+辉光）
- **五把武器**：AK-47 / SMG-11 / SG-870 / **SR-98 狙击枪（开镜）** / P-18，后坐力、动态散布、曳光、换弹动作
- **后期处理管线**：GTAO 环境光遮蔽 + UnrealBloom 辉光 + ACES 电影级色调映射
- **CC0 PBR 材质**：ambientCG 高清贴图（混凝土/泥土/沙地/锈金属/木箱），含法线与粗糙度贴图、环境反射
- **精细化角色**：头盔+发光面罩、防弹背心、背包、靴子、手套，细节武器模型
- 完整 HUD、加血包、出生/波次护盾、机器人 AI、小地图、WebAudio 音效

## 技术

- Three.js r160（ES Module，CDN 引入 three + addons）
- 后期处理：EffectComposer + GTAOPass + UnrealBloomPass + OutputPass
- PBR：ambientCG CC0 贴图（`assets/textures/`），PMREM 环境反射
- 贴图加载失败自动回退程序化贴图（离线/断网仍可玩，仅画面降级）
