# dsv4f-shot-game

CS 风格的单人第一人称射击网页游戏 —— **三张地图**可选：废弃军事基地（夜晚）、沙漠小镇（白昼）、霓虹实验室（赛博）。

基于 **Three.js**，纯原生 HTML/CSS/JS，无构建步骤，本地双击 `index.html` 即可运行。

## 运行方式

```bash
# 方式一：直接双击 index.html 打开
# 方式二：本地起一个静态服务器
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

线上版本已部署到 **Vercel**（见仓库主页）。

## 玩法

- 开始前可选择作战场景，对抗一波波刷新的恐怖分子机器人。
- 开局 **5 秒出生护盾**：免伤且敌人不会伤到你，让你有喘息空间。
- 地图上散布**加血包**（红光十字医疗箱），走近拾取回复 30 血。
- 存活击杀尽可能多的敌人，每波更强、更多；血量耗尽即阵亡，可重新出击。

## 功能特性

- **三张地图**：废弃军事基地（夜雾+探照灯）/ 沙漠小镇（阳光+土坯房）/ 霓虹实验室（冷色霓虹管线）
- **四把武器**：AK-47 / SMG-11 / SG-870 霰弹枪（8 弹丸散射）/ P-18，后坐力、动态散布、曳光、换弹动作
- **机器人 AI**：追击避障、视线开火、受击反馈、死亡动画、波次递增
- **加血包 + 出生护盾** + 完整 HUD（血量/护甲/弹药/准星/命中/击杀/波次/受伤方向/小地图）
- WebAudio 程序合成音效，零外部资源

## 技术

- Three.js r159（本地化 `vendor/three.min.js`，离线可用）
- 程序化 Canvas 贴图、ACES 电影级色调映射、实时阴影、粒子特效
